# PornGo

当前版本：**0.9.7**。版本变更见 [更新日志](CHANGELOG.md)。

Windows x64 用户可以从 [GitHub Releases](https://github.com/Chinsir0214/PornGo/releases/latest) 下载安装版或单文件便携版。两者都内置 yt-dlp 和 FFmpeg。

PornGo 是独立于 BiliGo 的 Windows Electron 下载器，支持 Pornhub 单视频、片单，以及色情明星和模特的视频页。应用使用内嵌网页窗口保存登录会话；解析与下载自动使用该会话，无需手动提取 Cookie，也无需选择外部浏览器。

## 运行

在 `PornGo` 目录执行：

```powershell
npm install
npm start
```

首次运行前，在 Windows PowerShell 中获取并校验下载工具：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/fetch-tools.ps1
```

如果新检出仓库时下载脚本遇到上游 404，请下载并运行 `PornGo-0.9.7-setup.exe`。将安装目录 `resources\tools` 中的 `yt-dlp.exe` 和 `ffmpeg.exe` 复制到仓库的 `tools` 目录，然后在仓库根目录运行 `npm run verify:tools`。[PornGo v0.9.7](https://github.com/Chinsir0214/PornGo/releases/tag/v0.9.7)

应用优先使用本仓库 `tools` 中的 `yt-dlp.exe`、`ffmpeg.exe`，也可使用系统 `PATH` 中的工具。固定版本、来源和 SHA-256 见 [tools/README.md](tools/README.md)。源码运行和打包都使用本仓库的工具，不依赖相邻项目。

```powershell
npm run check
npm test
```

## 独立打包

在 `PornGo` 目录运行 `npm run dist:portable`，只构建便携版；运行 `npm run dist` 则构建安装版和便携版。成品写入 `PornGo/release`。打包前会离线校验本仓库 `tools` 目录中的 yt-dlp 和 ffmpeg，缺失或校验失败时需先运行上面的获取命令。PornGo 使用自己的应用 ID、任务栏图标和浏览器资料目录，不与 BiliGo 共用安装包或网站会话。

## 使用

1. 点击“内嵌网页登录”，在弹出的 Pornhub 网页窗口完成登录和网站要求的验证码。应用会自动检查账户菜单，确认出现个人资料入口和“注销”后关闭登录窗口，并及时更新主界面的“最近确认登录”提示；无需手动展开头像菜单。未确认成功时窗口保持打开，也可手动关闭。应用不会仅凭 Cookie 断定账号已登录。会话保存在 PornGo 独立的浏览器资料中。
   若希望记住账号密码，在网页登录窗口填写账号密码后、提交登录前，使用窗口“账号密码”菜单中的保存操作（`Ctrl+Shift+S`），或主界面“保存网页登录账号密码”按钮。保存只在你主动操作时发生；之后再次打开同一网站登录页，应用会自动填充，也可使用菜单填充操作（`Ctrl+Shift+F`）或主界面“填入已保存账号密码”。填充不会提交登录，验证码和最终登录仍由你完成。更换账号或密码后可再次保存，替换原有记录。
2. 粘贴单个视频链接（`view_video.php?viewkey=...`、`video/show?viewkey=...` 或 `/embed/...`）、片单链接（`/playlist/{id}`），或色情明星、模特的视频页链接（`/pornstar/{name}`、`/model/{name}`，可带 `/videos`）。点击“解析链接”；明星页会列出当前页面解析到的视频。片单解析会核对各分页的视频总数，缺页时提示重新解析。
   明星和模特页默认全选。可按标题和链接逐条勾选，也可点击“全选”统一切换。点击明星标题栏即可收起或展开列表，标题栏始终显示已选数量。开始下载时只加入勾选的视频。
3. 确认解析出的内容和视频数量，选择画质后点击“开始下载”。默认保存到 Windows 当前用户的系统“下载”文件夹；也可点击“选择文件夹”更改保存位置，选择会在下次启动时恢复。如果原文件夹已不存在，则回退到系统“下载”文件夹。下载前可选择顺序或 4 片并发；片单和主页还可选择顺序或同时下载 2 条视频。批量任务显示当前条目和总进度。单条失败后会加入队列末尾，先继续其余条目，再重试；每条最多尝试 3 次，结束时报告成功与最终失败数量。并发下载时，进度区分别显示正在下载的视频的速度与预计剩余时间。可以取消正在运行的任务。
   调整单视频的分片并发时，会保留片单和主页的视频并发偏好。
4. 一项下载进行时，可粘贴并解析其他链接，再点击“加入下载队列”。多个链接的任务依次开始，进度区会显示等待数量；当前任务完成、失败或取消后会自动开始下一项。
   在“下载进度”中展开等待队列，或在其下方的“下载任务”中展开当前和已结束的任务，即可查看每条视频的状态及可用的进度、速率、剩余时间或错误。任务明细在本次应用运行期间保留。
   开始下载或加入队列时，任务使用界面当前显示的解析结果。
   每批任务结束后，“未成功的项目”会按批次列出最终失败的视频和原因。可逐条勾选或全选，再点击“重新下载选中项”；重下沿用该批原有画质、保存目录与并发设置，加入现有队列。下一批开始时，失败列表仍保留；重下成功的项目自动移除，重下失败或取消的项目可再次选择。直接取消任务不会把尚未开始或被中断的视频计为失败。列表只在当前应用会话中保留，关闭应用后不恢复。
5. 批量内容保存在以片单名或明星名命名的独立子文件夹中，文件夹名同时包含页面 ID，避免同名冲突。单视频与批量视频均使用“标题 [视频 ID]”作为文件名，不再添加列表序号；视频标题默认优先采用网站提供的简体中文，其次繁体中文，均无可用翻译时采用上传者原标题。此标题也用于下载进度和嵌入的视频标题元数据；网站翻译页面暂时无法读取时沿用下载工具取得的标题，不影响下载。列表有新内容、原视频位置变化时，文件名仍一致，再次下载会跳过同目录已存在的同名视频。已有带编号文件或不同标题的文件不做迁移或兼容识别。
6. 下载完成后会嵌入标题、作者、来源链接和网站提供的发布日期等视频元数据，并把最终视频文件的“修改日期”设置为发布时间。在 Windows 资源管理器中选择按“修改日期”排序即可按发布时间排列；有精确发布时间时保留时分秒，只有发布日期时使用该日 UTC 零点（资源管理器按本地时区显示）。网站未提供日期时保留正常下载时间。媒体日期字段的显示取决于文件格式及读取软件；系统“创建日期”不会改为发布时间。嵌入元数据需要 ffmpeg；后处理或时间设置失败会显示下载失败信息并按现有规则重试。
7. 点击“清除内嵌会话”可删除 PornGo 浏览器资料中的网站数据，保存的账号密码会保留。“删除保存的账号密码”会删除本机保存的账号密码；当前网站会话和登录页已填入的内容仍会保留。账号密码与网站会话分别管理。

账号密码仅在主动保存时写入 PornGo 的本机应用资料，使用 Electron `safeStorage` 和 Windows DPAPI 加密，不会以明文写入配置或发送给下载工具。主界面只显示保存状态，密码仅在可信的同一网站登录页中填充。本机加密不可用时会拒绝保存或填充；已保存记录仍可删除。下载时仅把目标站点的会话 Cookie 写入本机临时文件供 yt-dlp 使用，任务结束即删除。若应用异常退出，临时目录中可能留有 `porngo-*` 文件，请勿分享这些文件。仅下载你有权保存的内容。

## 已知限制

- 保存与填充仅支持 Pornhub HTTPS `/login` 登录页的可识别账号密码表单。自动填充在页面加载后的约 10 秒内尝试，保留你已输入的内容；页面加载较慢时可手动点击填充。其他页面的登录弹窗、注册/重置密码表单和第三方登录暂不支持。
- Google 登录按钮在 Electron 内嵌窗口中可能无法响应。可使用 Pornhub 邮箱密码在窗口内登录；验证码及其他网站交互须由用户自行完成。
- 单视频与明星页的视频提取依赖 yt-dlp。片单列表通过内嵌网页登录会话读取，因为当前网站对 yt-dlp 的片单网页请求可能返回 HTTP 410。片单中的每个视频仍由 yt-dlp 下载。
- 网站接口可能变动；如果片单分页结构改变，应用会在解析阶段报错，避免仅下载到片单的一部分。
- 个别视频虽然能解析和播放，媒体地址仍可能被服务器拒绝（HTTP 474）；提供的明星页在本次下载测试中就出现了此错误。应用会把失败项移到队尾重试，最多尝试 3 次；持续被拒绝时仍会计为失败。
- 暂未迁移 BiliGo 的收藏夹、弹幕、任务恢复、历史和更新发布流程。

项目代码均在此目录；不会改动 BiliGo 的登录与下载配置。
